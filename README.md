# MA-CODE

MA-CODE é um ecossistema digital em desenvolvimento que reúne produtos próprios, ferramentas web, experiências interactivas e projectos digitais construídos com foco em utilidade, simplicidade e evolução contínua.

O projecto não se limita a uma única aplicação: é composto por várias vertentes independentes, mas integradas sob a mesma identidade MA-CODE.

## Produtos e vertentes MA-CODE

### MA PDF

Conjunto de ferramentas para trabalhar com documentos PDF de forma simples e acessível. Inclui funcionalidades para juntar, dividir, comprimir, converter, editar e assinar ficheiros PDF, com uma experiência web moderna e preparada para pagamentos por MB WAY.

### MA Carteira

Carteira digital em desenvolvimento orientada para acompanhamento de endereços públicos. Permite guardar e identificar carteiras, consultar saldos e acompanhar histórico sem pedir seed phrases nem chaves privadas, privilegiando uma abordagem de leitura e segurança.

### MA-BTC ALERTAS

Sistema de alertas dedicado ao Bitcoin. Acompanha a evolução do par BTC/USD e pode enviar notificações quando é detectada uma variação acumulada relevante, incluindo mecanismos de controlo como períodos de consulta e snooze.

### MA-Recortes

Ferramenta de criação de recortes e stickers a partir de fotografias. Permite remover o fundo automaticamente ou fazer o recorte manualmente, corrigir detalhes e exportar os resultados em PNG transparente ou para utilização no WhatsApp.

### MA-Quadro

Editor visual de design para criação de publicações, stories, cabeçalhos, cartazes e outros conteúdos gráficos. Inclui texto, imagens, formas, camadas, modelos e exportação, com uma forte aposta em processamento e armazenamento local, sem necessidade de conta para as operações principais.

### MA-Professor

Plataforma de gestão pedagógica pensada para o trabalho diário dos professores. Reúne áreas como planificações, sumários, UFCD, avaliações, faltas, recuperações de aprendizagens, organização de dados e mecanismos de sincronização e cópia de segurança.

## Jogos e experiências interactivas

### Conquistador

Jogo de estratégia integrado no ecossistema MA-CODE. O projecto inclui lógica própria de jogo, mapa, portos, comércio, dados de costa, animações e componentes de matchmaking e multiplayer, incluindo integração com infraestrutura de backend.

## Projectos desenvolvidos pela MA-CODE

Além dos produtos próprios, o repositório inclui a base do portefólio de projectos digitais desenvolvidos pela MA-CODE para diferentes contextos e necessidades.

Entre os projectos apresentados encontram-se:

- **REO – Rádio Escolar Online** — PWA para rádio escolar, arquivo digital e reprodução de áudio, com integração com Google Drive e Google Sheets.
- **Rosa Maria Cabeleireiros** — website profissional com marcações online, agenda, painel administrativo e ferramentas de gestão diária.
- **Porto Exótico** — solução de e-commerce com catálogo, carrinho, checkout, consentimento de cookies, analytics, assistente de IA e backoffice.

## Administração e infraestrutura

## Desenvolvimento

Para instalar as dependências:

```bash
npm install
```

Para iniciar o ambiente de desenvolvimento:

```bash
npm run dev
```

Para gerar uma build de produção:

```bash
npm run build
```

Para executar os testes disponíveis:

```bash
npm test
```
