# MA-CODE

MA-CODE é um projecto digital em desenvolvimento que reúne ferramentas e experiências interactivas orientadas para educação, produtividade e criatividade.

## Principais áreas

- **MA-Professor** — aplicação dedicada à organização e apoio ao trabalho do professor, com armazenamento local, gestão de dados e funcionalidades de sincronização.
- **MA-Quadro** — editor visual para criação de conteúdos, com uma arquitectura baseada em React, Fabric.js e armazenamento local através de IndexedDB/Dexie.
- **Conquistador** — jogo de estratégia integrado no projecto, com suporte para partidas online e componentes próprios de matchmaking e lógica multiplayer.

## Tecnologias

O projecto utiliza, entre outras tecnologias:

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Fabric.js
- Dexie / IndexedDB
- pdf-lib / PDF.js
- Cloudflare Workers e serviços associados para funcionalidades de backend e multiplayer

## Desenvolvimento

```bash
npm install
npm run dev
```

Para gerar uma build de produção:

```bash
npm run build
```

Para executar os testes disponíveis:

```bash
npm test
```
